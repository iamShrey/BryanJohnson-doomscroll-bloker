# Publishing Checklist

Official publishing docs:

- https://developer.chrome.com/docs/webstore/publish
- https://developer.chrome.com/docs/webstore/images
- https://developer.chrome.com/docs/webstore/program-policies/policies
- https://developer.chrome.com/docs/webstore/program-policies/user-data-faq

## Prepared Files

- Extension ZIP: `dist/doomscroll-blocker-1.0.1.zip`
- Extension icon: `assets/icons/icon-128.png`
- Small promo image: `store-assets/small-promo.png`
- Screenshots:
  - `store-assets/screenshot-overlay.png`
  - `store-assets/screenshot-analytics.png`
- Privacy policy draft: `PRIVACY.md`
- Store listing draft: `STORE_LISTING.md`

## Dashboard Steps

1. Register or open the Chrome Developer Dashboard.
2. Add new item.
3. Upload `dist/doomscroll-blocker-1.0.1.zip`.
4. Fill Store Listing using `STORE_LISTING.md`.
5. Upload listing assets from `store-assets/`.
6. Fill Privacy fields accurately.
7. Use the privacy policy URL from this repository after it is pushed:
   `https://github.com/iamShrey/BryanJohnson-doomscroll-bloker/blob/main/PRIVACY.md`
8. Set distribution and visibility.
9. Submit for review.
