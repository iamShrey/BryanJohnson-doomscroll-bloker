# Privacy Policy

Last updated: May 3, 2026

Doomscroll Blocker is a Chrome extension that helps users interrupt excessive scrolling on configured websites.

## Data Processed Locally

The extension processes these signals in the browser:

- scroll distance and scroll speed
- current tab domain
- active block timer state
- broad content category derived locally from visible page text, if content insights are enabled
- aggregate local analytics such as total blocks, estimated interrupted time, top trigger domain, and top category

## Data Not Collected

The extension does not:

- send browsing activity to a server
- sell or share data
- store raw visible page text
- capture screenshots
- record keystrokes
- read pages outside the browser tab context
- use remote analytics services

## Storage

Settings are stored with `chrome.storage.sync`.
Active tab block timers are stored with `chrome.storage.session`.
Aggregate analytics are stored locally with `chrome.storage.local`.

Users can disable content insights in the extension popup. Users can also reset local analytics from the popup.
